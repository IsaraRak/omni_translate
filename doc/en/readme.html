OmniTranslate Documentation

OmniTranslate is a powerful, modern translation add-on for the NVDA screen reader featuring local neural AI offline translation, smart bidirectional routing, dual-engine online failover, accessible dialogs, 5 quick-switch language slots, and a conflict-free layered shortcut system.

Default Keyboard Shortcuts (Layered 2-Step Commands)

Press NVDA+Shift+T once to enter the command layer (a short beep will sound). After entering the layer, press one of the following sub-keys:

  • 1 - 5 (or Numpad 1 - 5): Switch target language directly to Quick Slot 1, 2, 3, 4, or 5 and translate instantly.
  • T: Translate selected text or clipboard content.
  • S: Toggle translation mode between Online (with offline fallback) and Offline Only.
  • V: Open the accessible Translation Result Viewer dialog.
  • H: Open Translation History dialog.
  • M: Toggle automatic speech output (Speech ON / Silent Mode).
  • R: Repeat the last translated text.
  • C: Copy last translation to clipboard.
  • O: Open OmniTranslate Settings dialog.
  • F1: Open Documentation.
  • Escape: Cancel layer mode.

Key Features

  • Offline Neural Machine Translation (Local AI): High-performance local neural translation powered by CTranslate2 (int8 quantization) and Meta's NLLB-200 models. 100% private, zero network latency, and no internet connection required.
  • Smart Bidirectional Translation: Automatically detects the input language across all major world writing systems. If text matches your primary target language, it automatically translates to your secondary language; otherwise, it translates to your primary target language.
  • Dual-Engine Failover: In Online mode, automatically falls back to secondary endpoints or local offline neural models if internet connectivity is lost or rate-limited.
  • Instant Quick Slots 1–5: Switch between your 5 most frequently used languages and translate instantly with keys 1 through 5.
  • Replace Selected Text in Editable Fields: Optional setting to automatically replace selected text in editable fields (Notepad, Word, chat boxes, web inputs) with the translated text upon translation.
  • Configurable Clipboard Fallback: Choose whether OmniTranslate translates clipboard contents when no text is selected, or strictly translates only highlighted text.
  • Quick Mode Toggle (Layer + S): Toggle instantly between Online and Offline translation modes with Layer + S without opening settings.
  • Zero-Latency Settings Panel: Smooth, lag-free mode switching with asynchronous UI dispatch and unified multilingual catalog caching.
  • Dual Settings Categories: Dedicated, accessible categories in NVDA Settings (OmniTranslate: General and OmniTranslate: Offline Models).
  • Accessible Result Viewer & History: Dedicated multi-line text viewer and in-memory session history for easy reading and enhanced privacy.
  • NMT Output Sanitizer: Automatically cleans dialogue hyphens (-) generated by neural models for natural, uninterrupted speech synthesis.

Offline Models & Custom Model Installation

OmniTranslate includes an in-app Model Manager located in NVDA Settings -> OmniTranslate: Offline Models.

Recommended Models (One-Click Download)

  • NLLB-200 600M (int8): ~600 MB download. Fast, lightweight, supports 100+ languages.
  • NLLB-200 1.3B (int8): ~1.3 GB download. Higher translation quality for complex texts.

Installing Custom / External Models

Users can manually add custom CTranslate2 models to OmniTranslate:

  1. Open NVDA Settings (NVDA Menu -> Preferences -> Settings, or press NVDA+Shift+T then O) -> OmniTranslate: Offline Models.
  2. Click the "Open Models Folder" button (or navigate to %APPDATA%\nvda\omni_translate_models).
  3. Paste your CTranslate2 model folder into this directory.

Custom Model Requirements:

  • Architecture: Must be converted to CTranslate2 format (e.g. Meta NLLB-200, M2M-100, Opus-MT / Marian models).
  • Required Files: model.bin, config.json, SentencePiece model (sentencepiece.bpe.model / source.spm / spm.model / opus.spm), and vocabulary file (shared_vocabulary.txt / shared_vocabulary.json).
  • Model Detection: Multilingual models automatically unlock all 100+ languages and bidirectional translation. Single-pair models will automatically lock to their supported pair.

Changelog

Version 2026.3 (Major Release)

  • Local Neural Offline Translation Engine: Integrated CTranslate2 int8 neural engine with Meta NLLB-200 and Opus-MT support for fast, private, and 100% offline translation without requiring an internet connection.
  • Universal Editable Selection Replacement: Added setting (Replace selected text with translation in editable fields) to automatically replace selected text directly with its translation across text editors (Notepad, Word), system dialogs (Windows Run Win+R), desktop/web chat boxes, and in-game chat message boxes (DirectX/OpenGL).
  • Instant Quick Slots Execution: Selecting Quick Slots 1–5 in layer mode now switches the target language and executes the translation immediately in a single step.
  • Keyboard Shortcut Adjustments: Updated keyboard shortcuts; removed the manual language swap shortcut (now handled automatically by Smart Bidirectional Translation) and replaced key S with the Translation Mode Toggle (Online / Offline) with audible confirmation.
  • Universal Smart Bidirectional Translation: Automatically detects input language across all major Unicode writing systems and unaccented Latin text, routing seamlessly between primary target and secondary languages.
  • Multiline & Paragraph Layout Preservation: Preserves exact newline layout, paragraph breaks, and lists (\n) during translation, preventing text from colliding into run-on blocks.
  • In-App Offline Model Manager: Manage and download recommended offline neural models (600M / 1.3B) directly within NVDA Settings with progress announcements, model deletion, and custom model import support.
  • Automatic Offline Failover: Seamlessly falls back to local offline neural models if internet connectivity is lost or online services are unavailable.
  • Configurable Clipboard Fallback: Added a dedicated setting (Translate text from clipboard when no text is selected) allowing users to control whether clipboard contents are translated when no text is actively highlighted.
  • Conflict-Free Layered Command System: Implemented NVDA+Shift+T 2-step gateway with numeric quick slots (1-5), T, S, V, H, M, R, C, O, and F1 to eliminate shortcut collisions.
  • Dual Settings Panels: Divided settings into OmniTranslate: General and OmniTranslate: Offline Models in NVDA Settings for clean, accessible organization.
  • Documentation Access: Integrated direct F1 documentation hotkey and standard Add-on Store help support.

Version 2026.2.1

  • Keyboard Shortcut Collisions Fix: Updated quick slot cycling to NVDA+Shift+J and repeat last translation to NVDA+Shift+Z to resolve shortcut conflicts.
  • Online Multi-Endpoint Protection: Added multi-endpoint rotation and web fallback to prevent HTTP 429 rate limit errors.
  • Enhanced Memory Storage: Changed history storage to session-only in-memory storage for privacy.
  • UI Refinement: Reordered settings controls for optimal screen reader accessibility.

Version 2026.2 (Initial Release)

  • Initial release with high-speed translation across 100+ languages.
  • 5 customizable quick-switch language slots.
  • Accessible Translation Result Viewer and Translation History dialogs.
  • Direct clipboard copying and speech toggling.
