OmniTranslate Documentation

OmniTranslate provides real-time bidirectional translation directly inside NVDA.

Default Keyboard Shortcuts

  • NVDA+Shift+T: Translate selected text or clipboard content.
  • NVDA+Shift+S: Swap secondary and target languages.
  • NVDA+Shift+J: Cycle through 5 configured target language slots.
  • NVDA+Shift+Z: Repeat the last translated text.
  • NVDA+Shift+V: Open Result Viewer dialog.
  • NVDA+Shift+H: Open Translation History dialog.
  • NVDA+Shift+C: Copy last translation to clipboard.
  • NVDA+Shift+M: Toggle speech output.
  • NVDA+Shift+O: Open Settings dialog.
