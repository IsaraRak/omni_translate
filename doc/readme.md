# OmniTranslate for NVDA

OmniTranslate is a powerful, modern translation add-on for the NVDA screen reader featuring local neural AI offline translation, smart bidirectional routing, dual-engine online failover, accessible dialogs, 10 quick-switch language slots, and a conflict-free layered shortcut system.

## Key Shortcuts (Layered 2-Step System)

OmniTranslate uses a conflict-free 2-step layered command system designed to prevent shortcut conflicts with NVDA and other applications:

1. **Entry Command**: Press **`NVDA + Shift + T`** once to enter the OmniTranslate layer.
2. **Sub-Commands** (press after entering the layer, within 15 seconds):
   * **`1` to `0`** (or Numpad 1 to 0; `0` = Slot 10): Switch target language directly to Quick Slot 1 through 10 and translate instantly (announces the new target language followed by the translation).
   * **`Shift + 1` to `Shift + 0`** (or Shift + Numpad 1 to 0): Switch source language directly to Quick Slot 1 through 10 (changes configuration with audible confirmation and speech announcement, **does not execute translation**).
   * **`T`**: Translate selected text or clipboard content.
   * **`S`**: Toggle translation mode between Online (with offline fallback) and Offline Only.
   * **`V`**: Open the accessible Translation Result Viewer dialog.
   * **`H`**: Open Translation History dialog.
   * **`M`**: Toggle automatic speech output (Speech ON / Silent Mode).
   * **`R`**: Repeat the last translated result.
   * **`C`**: Copy last translated result to clipboard.
   * **`O`**: Open OmniTranslate Settings dialog.
   * **`F1`**: Open OmniTranslate user documentation.
   * **`Escape`** (or wait 15 seconds): Cancel layer mode (with audio confirmation tone).

> **Note:** Users can also assign custom direct shortcuts to any of these individual commands via the **NVDA Menu -> Preferences -> Input Gestures** dialog under the *OmniTranslate* category.

## Key Features

- **Offline Neural Machine Translation (Local AI)**: High-performance local neural translation powered by CTranslate2 (int8 quantization) and Meta's NLLB-200 models. 100% private, zero network latency, and no internet connection required.
- **Smart Bidirectional Translation**: Automatically detects the input language across all major world writing systems. If text matches your primary target language, it automatically translates to your secondary language; otherwise, it translates to your primary target language.
- **Dual-Engine Failover**: In Online mode, automatically falls back to secondary endpoints or local offline neural models if internet connectivity is lost or rate-limited.
- **Dedicated Target and Source Quick Keys (1–10 & Shift+1–0)**: Configure up to 10 frequently used languages independently for target and source. Press `1`–`0` (`0` = Slot 10) to translate immediately to target slots, or `Shift + 1`–`Shift + 0` to quickly set your source language without translating. Configured via two dedicated buttons in the General Settings panel.
- **Automated Background Updates**: Silently and automatically checks for official GitHub releases in the background 10 seconds after NVDA starts up, eliminating NVDA startup freezing or modal disruptions while keeping the add-on up to date.
- **Intelligent Batch Chunking & Layout Preservation**: Automatically segments large documents up to 50,000 characters into contextual chunks (~3,000 characters) at natural paragraph or sentence boundaries. Delimiter-pairing architecture separates paragraph breaks (`\r\n\r\n`), blank lines, and bullet lists from translation payloads, guaranteeing 100% preservation of original layout and document structure upon reassembly.
- **Replace Selected Text in Editable Fields**: Optional setting to automatically replace selected text in editable fields (Notepad, Word, chat boxes, web inputs) with the translated text upon translation.
- **Configurable Clipboard Fallback**: Choose whether OmniTranslate translates clipboard contents when no text is selected, or strictly translates only highlighted text.
- **Quick Mode Toggle (Layer + S)**: Toggle instantly between Online and Offline translation modes with Layer + S without opening settings.
- **Zero-Latency Settings Panel**: Smooth, lag-free mode switching with asynchronous UI dispatch and unified multilingual catalog caching.
- **Dual Settings Categories**: Dedicated, accessible categories in NVDA Settings (`OmniTranslate: General` and `OmniTranslate: Offline Models`).
- **Accessible Result Viewer & History**: Dedicated multi-line text viewer and in-memory session history for easy reading and privacy, featuring quick Enter navigation to view history entries and instant Escape dismissal.
- **NMT Output Sanitizer**: Automatically cleans dialogue hyphens (`-`) generated by neural models for natural, uninterrupted speech synthesis.
- **Real-Time Model Busy-Guard & Safe Deletion Without Restart**: Active inference tracking prevents accidental deletion or corruption while a model is running. Deleting an idle model instantly unloads weights from RAM and cleans up disk files in milliseconds with zero NVDA restart required.
- **Optimized Memory & Neural Lifecycle Management**: Proactive single-active-model memory management, explicit C++ neural weight unloading upon plugin termination/reloads, and weak-reference background callbacks to guarantee minimal RAM footprint inside NVDA.

## Offline Models & Custom Model Installation

OmniTranslate includes an in-app Model Manager located in **NVDA Settings -> OmniTranslate: Offline Models**.

### Recommended Models (One-Click Download)
- **NLLB-200 600M (int8)**: ~600 MB download. Developed by Meta. Fast, lightweight, supports 200 languages. Ideal for everyday use on laptops and budget PCs.
- **NLLB-200 1.3B (int8)**: ~1.3 GB download. Developed by Meta. Higher translation quality and structural precision for complex and technical texts.
- **Google MADLAD-400 3B (int8)**: ~2.95 GB download. Developed by Google Research. Flagship 3B parameter multilingual model delivering exceptional translation accuracy and structural fidelity.

### Installing Custom / External Models
Users can manually add custom CTranslate2 models to OmniTranslate:
1. Open NVDA Settings (**NVDA Menu -> Preferences -> Settings**, or press **`NVDA + Shift + T`** then **`O`**) -> `OmniTranslate: Offline Models`.
2. Click the **"Open Models Folder"** button (or navigate to `%APPDATA%\nvda\omni_translate_models`).
3. Paste your CTranslate2 model folder into this directory.

#### Custom Model Requirements & Conditions:
- **Architecture**: Must be converted to CTranslate2 format (e.g. Meta NLLB-200, Google MADLAD-400, M2M-100, Opus-MT / Marian models).
- **Required Files inside Model Folder**:
  - `model.bin` (the quantized neural model weights)
  - `config.json` (model configuration)
  - SentencePiece Tokenizer file (one of: `sentencepiece.bpe.model`, `source.spm`, `spm.model`, `spiece.model`, `sentencepiece.model`, or `opus.spm`)
  - `shared_vocabulary.txt` or `shared_vocabulary.json` (for vocabulary resolution)
- **Model Detection**:
  - **Multilingual models** (containing NLLB/MADLAD/M2M language tags or named `nllb`, `madlad`, `m2m`, `multilingual`): OmniTranslate will automatically unlock all 100+ languages, Quick Slots 1–10, and Smart Bidirectional translation.
  - **Single-pair bilingual models** (e.g., folder named `opus-mt-en-th` or `de-en`): OmniTranslate will automatically detect the supported pair and adapt translation accordingly.

### Model Management, Memory Optimization & Storage Hygiene:
- **Intelligent 10-Minute Online Idle Memory Auto-Reclaim**: When running in Online Mode, if an offline model is resident in RAM (from previous offline translation or offline fallback), OmniTranslate monitors offline activity. If no offline translation is triggered for 10 minutes, the model is safely unloaded from memory and its footprint released back to Windows. This frees up ~1.2 GB to ~3.5+ GB of RAM while keeping the model intact on disk for immediate re-use. Switching to Offline Mode instantly cancels the countdown to keep the model warm in memory.
- **Real-Time Busy Guard**: If you attempt to delete or switch an offline model while a translation or batch inference is actively running, OmniTranslate protects against crashes and Windows file-sharing violations (`ERROR_SHARING_VIOLATION`) by immediately alerting you with an audible tone and speech notification without freezing NVDA.
- **Instant Deletion Without Restart**: When deleting an idle model via NVDA Settings, OmniTranslate safely unloads neural weights from memory to release OS file handles, then immediately deletes the folder in milliseconds. **No NVDA restart is required.**
- **Automatic Storage Hygiene**: Model downloads stream into `.part` temporary files and atomically rename only after complete package verification. Failed downloads and downloaded add-on update packages in `%TEMP%` are unconditionally purged, ensuring zero orphaned or corrupted files remain on disk.
