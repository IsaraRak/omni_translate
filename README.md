# OmniTranslate for NVDA
**OmniTranslate** is a high-speed, all-in-one accessible translation add-on for the NVDA Screen Reader, supporting more than 100 languages worldwide.
## Features
* **Dual-Engine Architecture:** High-speed stateless translation backed by intelligent failover.
* **Full Unicode Support:** Native support for Korean (Hangul), Japanese (Kanji/Kana), Chinese, Thai, Arabic, and 100+ languages.
* **Paragraph Translation:** Smoothly translates full paragraphs and multi-line text without truncating.
* **Customizable Quick-Cycle Slots:** 5 user-configurable quick target language slots.
* **Accessible History & Viewer:** Built-in Result Viewer and 10-item Translation History.
* **Global Low Latency:** Optimized for global Edge routing.
## Keyboard Shortcuts
* NVDA + Shift + T : Translate selected text or clipboard content.
* NVDA + Shift + S : Swap source and target languages.
* NVDA + Shift + L : Quick-cycle target language across configured slots.
* NVDA + Shift + V : Open Result Viewer dialog.
* NVDA + Shift + H : Open Translation History dialog.
* NVDA + Shift + M : Toggle speech output (ON / Silent Mode).
* NVDA + Shift + A : Announce last translated text.
* NVDA + Shift + C : Copy last translated text to clipboard.
* NVDA + Shift + O : Open Settings dialog.
