# OmniTranslate for NVDA

OmniTranslate is a powerful, modern translation add-on for the NVDA screen reader featuring local neural AI offline translation, smart bidirectional routing, dual-engine online failover, accessible dialogs, 10 quick-switch language slots, and a conflict-free layered shortcut system.

## Key Shortcuts (Layered 2-Step System)

OmniTranslate uses a conflict-free 2-step layered command system designed to prevent shortcut conflicts with NVDA and other applications:

1. **Entry Command**: Press **`NVDA + Shift + T`** once to enter the OmniTranslate layer (a short beep will sound).
2. **Sub-Commands** (press after entering the layer):
   * **`1` to `0`** (or Numpad 1 to 0; `0` = Slot 10): Switch target language directly to Quick Slot 1 through 10 and translate instantly.
   * **`Shift + 1` to `Shift + 0`** (or Shift + Numpad 1 to 0): Switch source language directly to Quick Slot 1 through 10 (changes configuration with audible confirmation, **does not execute translation**).
   * **`T`**: Translate selected text or clipboard content.
   * **`S`**: Toggle translation mode between Online (with offline fallback) and Offline Only.
   * **`V`**: Open the accessible Translation Result Viewer dialog.
   * **`H`**: Open Translation History dialog.
   * **`M`**: Toggle automatic speech output (Speech ON / Silent Mode).
   * **`R`**: Repeat the last translated result.
   * **`C`**: Copy last translated result to clipboard.
   * **`O`**: Open OmniTranslate Settings dialog.
   * **`F1`**: Open OmniTranslate user documentation.
   * **`Escape`**: Cancel layer mode.

> **Note:** Users can also assign custom direct shortcuts to any of these individual commands via the **NVDA Menu -> Preferences -> Input Gestures** dialog under the *OmniTranslate* category.

## Key Features

- **Offline Neural Machine Translation (Local AI)**: High-performance local neural translation powered by CTranslate2 (int8 quantization) and Meta's NLLB-200 models. 100% private, zero network latency, and no internet connection required.
- **Smart Bidirectional Translation**: Automatically detects the input language across all major world writing systems. If text matches your primary target language, it automatically translates to your secondary language; otherwise, it translates to your primary target language.
- **Dual-Engine Failover**: In Online mode, automatically falls back to secondary endpoints or local offline neural models if internet connectivity is lost or rate-limited.
- **Dedicated Target and Source Quick Keys (1–10 & Shift+1–0)**: Configure up to 10 frequently used languages independently for target and source. Press `1`–`0` (`0` = Slot 10) to translate immediately to target slots, or `Shift + 1`–`Shift + 0` to quickly set your source language without translating. Configured via two dedicated buttons in the General Settings panel.
- **Replace Selected Text in Editable Fields**: Optional setting to automatically replace selected text in editable fields (Notepad, Word, chat boxes, web inputs) with the translated text upon translation.
- **Configurable Clipboard Fallback**: Choose whether OmniTranslate translates clipboard contents when no text is selected, or strictly translates only highlighted text.
- **Quick Mode Toggle (Layer + S)**: Toggle instantly between Online and Offline translation modes with Layer + S without opening settings.
- **Zero-Latency Settings Panel**: Smooth, lag-free mode switching with asynchronous UI dispatch and unified multilingual catalog caching.
- **Dual Settings Categories**: Dedicated, accessible categories in NVDA Settings (`OmniTranslate: General` and `OmniTranslate: Offline Models`).
- **Accessible Result Viewer & History**: Dedicated multi-line text viewer and in-memory session history for easy reading and privacy, featuring quick Enter navigation to view history entries and instant Escape dismissal.
- **NMT Output Sanitizer**: Automatically cleans dialogue hyphens (`-`) generated by neural models for natural, uninterrupted speech synthesis.

## Offline Models & Custom Model Installation

OmniTranslate includes an in-app Model Manager located in **NVDA Settings -> OmniTranslate: Offline Models**.

### Recommended Models (One-Click Download)
- **NLLB-200 600M (int8)**: ~600 MB download. Fast, lightweight, supports 100+ languages.
- **NLLB-200 1.3B (int8)**: ~1.3 GB download. Higher translation quality for complex texts.

### Installing Custom / External Models
Users can manually add custom CTranslate2 models to OmniTranslate:
1. Open NVDA Settings (**NVDA Menu -> Preferences -> Settings**, or press **`NVDA + Shift + T`** then **`O`**) -> `OmniTranslate: Offline Models`.
2. Click the **"Open Models Folder"** button (or navigate to `%APPDATA%\nvda\omni_translate_models`).
3. Paste your CTranslate2 model folder into this directory.

#### Custom Model Requirements & Conditions:
- **Architecture**: Must be converted to CTranslate2 format (e.g. Meta NLLB-200, M2M-100, Opus-MT / Marian models).
- **Required Files inside Model Folder**:
  - `model.bin` (the quantized neural model weights)
  - `config.json` (model configuration)
  - SentencePiece Tokenizer file (one of: `sentencepiece.bpe.model`, `source.spm`, `spm.model`, or `opus.spm`)
  - `shared_vocabulary.txt` or `shared_vocabulary.json` (for vocabulary resolution)
- **Model Detection**:
  - **Multilingual models** (containing NLLB/M2M language tags or named `nllb`, `m2m`, `multilingual`): OmniTranslate will automatically unlock all 100+ languages, Quick Slots 1–10, and Smart Bidirectional translation.
  - **Single-pair bilingual models** (e.g., folder named `opus-mt-en-th` or `de-en`): OmniTranslate will automatically detect the supported pair and adapt translation accordingly.

## Changelog

### Version 2026.4
* **Expanded Quick Slots 1–10 & Quick Source Language Switching**:
  - Expanded quick language slots from 5 to 10. Pressing numeric keys `1` through `0` in layer mode (`0` = Slot 10) instantly switches target language and translates selected text or clipboard content.
  - Added quick source language switching via `Shift + 1` through `Shift + 0` in layer mode (`NVDA+Shift+T`). Pressing Shift with a slot key updates the configured secondary source language (`sourceLang`) with audible speech and tone confirmation without re-translating.
  - Replaced inline combo boxes with two dedicated buttons in General Settings: *Configure Target Language Quick Keys...* and *Configure Source Language Quick Keys...*, allowing independent customization for both translation directions via accessible dialogs.
* **Google HTTP 500 / 429 HTML Error Response Guard & Smart Input Handling**:
  - Fixed an issue where temporary Google server outages or anti-abuse rate limits leaked raw HTML error pages into user speech, result viewers, or clipboard output.
  - Integrated an infrastructure-level HTML error validator across online endpoints that immediately detects internal server errors while preserving user text containing programming error terms.
  - Enhanced multi-tier failover so that detected HTML errors from online services instantly trigger the local offline neural model (NLLB-200) without interrupting speech or displaying raw HTML code.
* **Security Hardening & Privacy Safeguards**:
  - Added automatic detection of password and protected fields, as well as clipboard content marked sensitive by password managers (`Clipboard Viewer Ignore`), to immediately abort translation and prevent credential leakage over network connections, session history, or speech synthesis.
  - Fully compliant with NVDA Secure Mode on Windows Logon, Lock Screen, and UAC elevation dialogs, eliminating Local Privilege Escalation (LPE) attack surfaces.
  - Bypassed synthetic `Ctrl+C` selection probes when focused inside command-line and terminal applications (`cmd.exe`, PowerShell, Windows Terminal, PuTTY) to prevent sending unintended interruption signals (`SIGINT`) to active processes.
  - Enforced path traversal prevention and strict directory validation for offline model management and deletion.
  - Secured automatic update checker with HTTPS enforcement and GitHub domain whitelist validation.
  - Implemented atomic configuration saving with temporary file replacement to protect against configuration corruption or 0-byte files during unexpected shutdowns.
* **Accessible Dialog UX & Keyboard Navigation Enhancements**:
  - In the Translation History dialog (`Layer + H`), pressing `Enter` or `Numpad Enter` directly on any history entry opens the full translation viewer immediately.
  - Pressing `Escape` now cleanly and reliably closes both the Translation Result Viewer (`Layer + V`) and Translation History (`Layer + H`) modal dialogs.

### Version 2026.3.1
* **Automatic Background Update Checker**: Integrated a lightweight, background update checker that monitors GitHub Releases for new versions and offers one-click seamless installation while fully preserving user configurations and offline models.
* **Multiline & Paragraph Layout Preservation**: Advanced paragraph-by-paragraph translation pipeline preserving exact newline layouts, blank line separators, numbered lists ("1.", "2.", "3."), and bullet items using standard Windows CRLF (`\r\n`) formatting, preventing sentence cutoffs and text block collisions.
* **Seamless Settings & Offline Model Retention on Upgrade**: Enhanced add-on lifecycle management (`installTasks.py`) to automatically detect version upgrades, safely preserving user configuration (`omni_translate_config.json`) and all downloaded neural models across add-on updates.

### Version 2026.3 (Major Release)
* **Local Neural Offline Translation Engine**: Integrated CTranslate2 int8 neural engine with Meta NLLB-200 and Opus-MT support for fast, private, and 100% offline translation without requiring an internet connection.
* **Universal Editable Selection Replacement**: Added setting (`Replace selected text with translation in editable fields`) to automatically replace selected text directly with its translation across text editors (Notepad, Word), system dialogs (Windows Run `Win+R`), desktop/web chat boxes, and in-game chat message boxes (DirectX/OpenGL).
* **Instant Quick Slots Execution**: Selecting Quick Slots `1`–`5` in layer mode now switches the target language and executes the translation immediately in a single step.
* **Keyboard Shortcut Adjustments**: Updated keyboard shortcuts; removed the manual language swap shortcut (now handled automatically by Smart Bidirectional Translation) and replaced key `S` with the **Translation Mode Toggle** (Online / Offline) with audible confirmation.
* **Universal Smart Bidirectional Translation**: Automatically detects input language across all major Unicode writing systems and unaccented Latin text, routing seamlessly between primary target and secondary languages.
* **In-App Offline Model Manager**: Manage and download recommended offline neural models (600M / 1.3B) directly within NVDA Settings with progress announcements, model deletion, and custom model import support.
* **Automatic Offline Failover**: Seamlessly falls back to local offline neural models if internet connectivity is lost or online services are unavailable.
* **Configurable Clipboard Fallback**: Added a dedicated setting (`Translate text from clipboard when no text is selected`) allowing users to control whether clipboard contents are translated when no text is actively highlighted.
* **Conflict-Free Layered Command System**: Implemented `NVDA+Shift+T` 2-step gateway with numeric quick slots (`1`-`5`), `T`, `S`, `V`, `H`, `M`, `R`, `C`, `O`, and `F1` to eliminate shortcut collisions.
* **Dual Settings Panels**: Divided settings into `OmniTranslate: General` and `OmniTranslate: Offline Models` in NVDA Settings for clean, accessible organization.
* **Documentation Access**: Integrated direct F1 documentation hotkey and standard Add-on Store help support.
