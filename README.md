# OmniTranslate for NVDA
OmniTranslate is a robust, bidirectional translation add-on for the NVDA screen reader.
## Key Shortcuts
* **NVDA + Shift + T**: Translate selected text or clipboard content.
* **NVDA + Shift + S**: Swap secondary and target languages.
* **NVDA + Shift + J**: Cycle through 5 configured quick-switch target language slots.
* **NVDA + Shift + Z**: Repeat the last translated result.
* **NVDA + Shift + V**: Open the accessible Translation Result Viewer.
* **NVDA + Shift + H**: Open Translation History dialog.
* **NVDA + Shift + C**: Copy last translated result to clipboard.
* **NVDA + Shift + M**: Toggle automatic speech output.
* **NVDA + Shift + O**: Open OmniTranslate Settings dialog.
